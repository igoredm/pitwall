**Português**

- **Espaço em disco fora de "O que segurou o FPS":** ele não muda durante a partida, então não conta mais como tempo acima do limite crítico. Partidas antigas também deixam de mostrar esse aviso.
- **Leitura falsa de disco cheio corrigida:** um disco sem volume que o Windows consiga ler (uma partição Linux, por exemplo) aparecia com quase 100% de uso. Agora ele não mostra "espaço usado"; temperatura e atividade continuam.
- Métricas de disco nos relatórios aparecem com o nome real do disco.

> Ainda sem assinatura digital: o Windows pode mostrar o SmartScreen (*Mais informações → Executar assim mesmo*). Confira o hash em `SHA256SUMS.txt`.

**English**

- **Disk space removed from "What held the FPS back":** it doesn't change during a session, so it no longer counts as time above the critical limit. Past sessions stop showing that notice too.
- **False "disk full" reading fixed:** a disk with no volume Windows can read (a Linux partition, for example) showed almost 100% used. It no longer shows "space used"; temperature and activity stay.
- Disk metrics in reports now show the disk's real name.

> Not code-signed yet: Windows may show SmartScreen (*More info → Run anyway*). Check the hash in `SHA256SUMS.txt`.
